# 📚 Library Management System

A Java-based Library Management System built for **Soweto Central Public Library**.  
Designed to manage staff operations, member activity, and book inventory from a single system.

## 🚀 Features

- Multi-user login system (Staff & Member)
- Book search by title, author, and genre
- Borrow and return tracking
- Staff admin controls for managing books and members
- Simple menu-driven console interface

## 🛠️ Built With

- Java
- IntelliJ IDEA

## ▶️ How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Navigate to `src/Main.java`
4. Run the `main` method
